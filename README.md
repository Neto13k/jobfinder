# jobfinder
Bot de busca de vagas de tecnologia que utiliza APIs e inteligência artificial para identificar oportunidades compatíveis com o perfil profissional e enviar notificações pelo Telegram.

## Estrutura inicial

- `src/config/`: configurações da aplicação.
- `src/providers/`: fontes externas de vagas.
- `src/services/`: serviços e regras de negócio.
- `src/types/`: tipos compartilhados, incluindo `Job`.
